1. No Collection of Personal Information
The PassGen extension does not collect, store, or transmit any personal information or user data. We do not track your browsing history, nor do we access any private data on the websites you visit.

2. Data Storage
Any configurations or settings created within the extension are stored locally on your device via the chrome.storage API. This data is not uploaded to any remote servers and is deleted when the extension is uninstalled.

3. Third-Party Services
The extension does not use any third-party analytics (e.g., Google Analytics), advertising tracking, or external scripts.

4. Changes to This Policy
If this policy is updated in the future, the changes will be reflected in the extension's version notes.

5. Contact
If you have any questions, you can contact the developer via the support channel in the Chrome Web Store.
